# Modul Haritasi

## Platform Domaini
- Identity/Auth: kullanici, session, refresh, MFA, login guvenligi
- Platform RBAC: platform operator rolleri
- Tenant Lifecycle: tenant olusum, durum, domain, branding
- Subscription/Billing: planlar, kullanim, faturalama, tahsilat
- Support/Ops: support access, operational loglar

## Tenant ERP Domaini
- Organization: sube, depo, kasa, ekip
- Product/Catalog: urun karti, varyant, barkod, lot/seri
- Pricing: fiyat listesi, kampanya, iskonto, promosyon
- Inventory: stok hareketleri, transfer, sayim, rezervasyon
- Sales/POS: kasa oturumu, satis, askiya alma, iade, fis
- Purchasing: siparis, mal kabul, alis faturasi
- Current Account: cari hareket, vade, limit, tahsilat/odeme
- Cash/Bank: kasa/banka hareketleri, kapanis, mutabakat
- Expense: masraf yonetimi
- Invoice/Dispatch: fatura/irsaliye/numara serisi
- e-Transformation: e-Fatura/e-Arsiv adaptoru
- Payment: odeme linki, webhook, iade
- Reporting: dashboard snapshot, KPI, export
- Workflow: onay akislar
- Audit/Security: islem gecmisi, anomali loglari
- Files/Documents: belge klasoru, etiket, iliski
- Notifications: e-posta/SMS/in-app templating
